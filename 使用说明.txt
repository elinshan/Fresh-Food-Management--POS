丰食生鲜 · 蔬菜店铺销售管理系统（本地版）
==========================================

一、启动
方式 A（推荐）：双击「丰食生鲜管理系统.exe」
  - 不需要电脑装 Python，后台无窗口运行，自动打开浏览器进入登录页
  - 若程序已在运行，再次双击只会把已有页面重新打开，不会重复启动
方式 B：双击「启动系统.bat」（需要电脑装 Python 3，会带一个命令行窗口）
  - 程序会自动打开浏览器并进入登录页
默认账号 admin    默认密码 123456
首次登录后可在「系统设置 → 账号安全」中修改密码

二、关闭
方式 A（exe 版）：在浏览器里点「系统设置 → 数据管理 → ⏻ 关闭系统」，确认后程序退出；
             页面会提示「系统已关闭」，直接关掉浏览器标签页即可。
             注意：只关浏览器不会退出程序，下次双击图标会自动恢复原页面。
方式 B（bat 版）：关闭黑色命令行窗口（或按 Ctrl+C）即退出。
所有改动在操作时已即时写入数据库，关闭窗口、重启电脑都不会丢失。

三、目录结构
fengshi-pos/
├─ 启动系统.bat            双击启动（需要电脑装 Python 3）
├─ 丰食生鲜管理系统.exe    双击启动（免安装版，不需要 Python）
├─ server.py               Python 3 标准库本地服务（无需安装任何第三方包）
├─ web/
│  └─ index.html           绿色 POS 风格前端界面
├─ data/
│  └─ fengshi.db           SQLite 数据库（所有业务数据）
└─ 打包工具/               重新打包 exe、生成安装包用的脚本与说明

两种启动方式共用同一份 data\fengshi.db，数据完全互通。
exe 请放在有写权限的普通目录（如 D:\丰食生鲜\），不要放进 Program Files。

四、店铺名称、LOGO 与小票打印选项
在「系统设置 → 店铺信息」里：
- 店铺名称：保存后左上角、顶栏、打印票据和浏览器标题都会同步更新
- 店铺 LOGO：点「选择图片」上传（PNG / JPG，建议方形），图片会自动等比压缩后存入数据库，
  左上角即替换为你的 LOGO；点「移除 LOGO」恢复默认 🥬
- 小票打印选项：感谢语 / 店铺电话 / 店铺地址 三项可分别勾选，未勾选的不会打印在销售单底部

五、数据备份与恢复
备份：系统设置 → 数据管理 →「下载数据备份」，得到 fengshi-YYYYMMDD.db
恢复：关闭系统 → 将备份文件改名为 fengshi.db 覆盖 data 目录下的同名文件 → 重新启动
     （覆盖前建议先把现有 fengshi.db 复制一份留底）

六、说明
- 服务只监听本机 127.0.0.1，局域网内其他电脑无法访问，数据不外传
- 默认端口 8765，若被占用会自动顺延到 8766~8770
- 「恢复初始演示数据」会把业务数据重置为演示内容，登录密码重置为 123456
- 打印销售单时会显示客户名称、联系电话、客户地址；店铺名与「销售单」并排显示在票头
- 打印统计报表、商户月报时，全部数据合并为一张表格（合计行 + 分组行），不再分卡片显示
- 打印会调用浏览器打印窗口，需允许弹出窗口
- exe 版的运行日志在 data\app.log，出问题时可查看
- 更新过程序文件后，请先「⏻ 关闭系统」再重新打开程序，新功能才会生效
- 浏览器需支持 ES6（Chrome / Edge / Firefox 均可）
